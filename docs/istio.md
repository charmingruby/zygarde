# Istio Sidecar Mode

## Setup

1. Download `istioctl`;
2. Install Istio on your cluster: `istioctl install`;
3. Install Kubernetes Gateway CRDs;
4. Install Kiali (optional, only for o11y);

**All this setup rules are abstracted into the "scaffold" Taskfile command.**
